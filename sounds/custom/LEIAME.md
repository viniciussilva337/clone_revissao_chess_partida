# Sons personalizados

Coloque aqui seus próprios sons (por exemplo, baixados do [Pixabay](https://pixabay.com/sound-effects/search/chess/),
que permite uso gratuito) com estes nomes, em **.mp3**:

| Arquivo | Quando toca | Obrigatório? |
|---|---|---|
| `move.mp3` | lance normal | sim |
| `capture.mp3` | captura | não (usa `move.mp3`) |
| `castle.mp3` | roque | não (usa `move.mp3`) |
| `check.mp3` | xeque | não (usa `move.mp3`) |
| `promote.mp3` | promoção | não (usa `move.mp3`) |
| `end.mp3` | fim de jogo | não |

Depois é só fazer commit, esperar o GitHub Pages atualizar e escolher
**Configurações → Sons do tabuleiro → Personalizado**.
